# Задачи по конструкторам в C#

Решения заданий из файла «Конструкторы задания с#.docx» собраны в `Program.cs`. Внутри есть простые конструкторы, перегрузки, цепочка `this`, проверка входных данных, вычисление значений, статический счётчик, наследование через `base` и конструктор копирования.

Для запуска откройте эту папку в Visual Studio или выполните `dotnet run` из неё. Примеры запуска находятся в `Main`; решения остальных заданий представлены отдельными классами.
